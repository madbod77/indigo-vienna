# Indigo — вступ до Австрії та Німеччини

Сайт українською з двома окремими напрямами: умови вступу, бакалаврат і магістратура, мова та підготовка, бюджет, послідовність дій і відповіді на поширені запитання. Головна дія — заявка на безкоштовну консультацію Indigo.

Цей пакет містить локальне доопрацювання для комп’ютера й телефона. Публічний сайт цим оновленням ще не змінено.

- Сайт: https://madbod77.github.io/indigo-vienna/
- Австрія: https://madbod77.github.io/indigo-vienna/?country=at#guide
- Німеччина: https://madbod77.github.io/indigo-vienna/?country=de#guide
- Код: https://github.com/madbod77/indigo-vienna

## Запуск і публікація

Node.js 22.13+ (рекомендовано Node 24):

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Відкрийте адресу сервера зі шляхом `/indigo-vienna/`. `site.config.ts` задає базовий шлях. GitHub Pages публікує попередньо зібраний каталог `docs` із гілки `main`: після перевірки збірки оновіть `docs` точним вмістом `dist` і закомітьте.

Перевірки коду:

```sh
npx tsc --noEmit
npm run lint
```

## Інтерфейс

Редакційна композиція на теплому світлому фоні: великі заголовки Georgia, системний шрифт у довіднику, глибокий індиго та наявні архітектурні фотографії. На широких екранах текст і країна стоять поруч, на телефоні — послідовно. Є мобільне меню та швидкі переходи до умов вступу, бюджету, кроків і FAQ. Фото не рухаються самостійно. Перемикач зберігає поточну швидкість пружини при повторному натисканні, а країна одночасно змінюється у всьому довіднику й формі.

Верстка підтримує вузькі екрани та збільшення тексту: перемикач може стати вертикальним, а його індикатор переміщується за реальною геометрією кнопок. Передбачено `prefers-reduced-motion`, `prefers-reduced-transparency`, підвищений контраст і видимий фокус клавіатури. Порожні обов’язкові поля отримують пояснення поруч із полем.

Фінальне доопрацювання для комп’ютера й телефона від 24.09.2026:

- На телефоні кроки вступу йдуть одним читабельним списком із номерами збоку; основні кнопки, навігація та посилання на джерела мають зону натискання заввишки щонайменше 44 px.
- Мобільне меню закривається після вибору розділу, натискання поза меню, виходу фокусу або Escape. Escape повертає фокус на кнопку меню.
- Обидві фотографії мають WebP-версії 800/1200/1600 px з `srcset` і `sizes`. Браузер обирає розмір під екран і щільність пікселів. Пара 800 px займає 163 184 байти замість 1 161 053 байтів оригінальних JPEG (−86%); старі оригінали та їхні ліцензії збережені. На екранах із високою щільністю браузер може обрати більші версії.
- Нативна кнопка підготовки заявки зберігає валідацію, доступність і вигляд, зменшуючи production JavaScript з 275,3 до приблизно 237,5 КБ (до gzip).

## Зміст і заявка

- `app/admissions.ts`: окремі відомості й офіційні джерела для кожної країни. Перевірено 19.09.2026; плата, пільги та вступні правила потребують перевірки перед наступним набором.
- Оновлення дизайну від 24.09.2026 зберігає `app/admissions.ts` байт у байт від `576d724`: 158 полів двох країн, 6 описів вступу, 8 кроків, 20 FAQ та всі джерела. Дату перевірки умов не змінено: це оновлення вигляду та повноти вмісту, не новий аудит вступних правил.
- `app/universities.ts`: повернуто 10 закладів Відня зі старої версії `c7fd28f` — назви, категорії, описи й офіційні посилання. Список розгортається в розділі Австрії; він не є рейтингом або переліком партнерів. Повернуто також локальні назви й описи країн із наявних даних.
- `app/editorial.css`: стилі оновленої композиції. Фотоблок має природну висоту, щоб збільшений текст і перемикач не перекривалися.
- `app/page.tsx`: вибір країни з прямими посиланнями, FAQ та форма.
- Форма перевіряє обов’язкові поля й показує текст заявки. Посилання відкриває чат `@Natalia_Indigo` з підготовленим текстом. Користувач сам натискає «Надіслати» в Telegram; сайт не показує вигаданого підтвердження відправлення. Є копіювання тексту та повернення до редагування.
- Дані форми не зберігаються на сервері або в localStorage. Telegram отримує текст лише після відкриття відповідного посилання. Немає прихованих відправлень, API-ключів чи платного сервісу.
- Відгуки, особисті дані консультантів і твердження про партнерства не вигадуються. Ці матеріали можна додати після підтвердження.
- Попереднє відео більше не використовується на сторінці й не завантажується під час перегляду. Історичні медіафайли залишені в репозиторії.
