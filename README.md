# Indigo — університети Відня

Інтерактивний сайт українською: індигова скляна кнопка запускає 23,25-секундний ролик, після якого можна переглядати 10 університетів Відня та перейти до консультації Indigo.

## Посилання

- Демо: https://madbod77.github.io/indigo-vienna/
- Код: https://github.com/madbod77/indigo-vienna

## Запуск

Потрібен Node.js 22.13+ (рекомендовано Node 24).

```sh
npm ci
npm run dev
```

Відкрийте адресу dev-сервера з шляхом `/indigo-vienna/`.

```sh
npm run build
npm run preview
```

Статичний результат: `dist`. Шлях GitHub Pages налаштовано в `site.config.ts`; для розміщення в корені домену встановіть `basePath = ''`. GitHub Pages публікує перевірену статичну збірку з теки `docs` у гілці `main`. Після змін виконайте `npm run build`, оновіть `docs` вмістом `dist` і закомітьте результат.

## Вміст

- React + Vite + Tailwind CSS; компоненти Button/Carousel на базі shadcn/ui та Embla.
- Ручний запуск, пауза, повторне відтворення, клавіатурна навігація та reduced-motion.
- Єдиний незмінний відеофайл для desktop/mobile; весь кадр 16:9 збережено. На телефоні відео й перший WU-екран мають біле тло та читабельний темний текст; нічого не обрізається.
- Фільм 23,25 с / 558 кадрів / 24 fps: рукописний Indigo → Земля → WU Wien. Видалено лише останні 0,75 с статичного утримання; активні рухи й стики не змінені.
- Посилання на офіційні правила вступу наведено для кожного закладу. Зображення — архітектурні візуалізації; добірка не є рейтингом або переліком партнерів.

Проєкт не потребує API-ключів, бази даних чи платних сервісів. Публікується лише статичний сайт, без серверної частини. Походження запозичених компонентів і ліцензійні повідомлення: `THIRD_PARTY_NOTICES.md`.
