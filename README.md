# Indigo — вступ до Австрії, Німеччини та Нідерландів

Наявний сайт Indigo з українським довідником для трьох країн. React 19 + TypeScript + Vite. Публічна адреса: https://madbod77.github.io/indigo-vienna/. Нідерланди додано в216 й опубліковано в220. Версія222 додає добірку університетів Німеччини.

## Університети Німеччини, хід222

- Рівно дев’ять закладів у порядку власника: Freie Universität Berlin, Technische Universität München, Universität Hamburg, Universität Leipzig, Technische Universität Dresden, Universität Bonn, Universität Heidelberg, Humboldt-Universität zu Berlin, RWTH Aachen University.
- `app/germany-universities.ts`: місто, короткі напрями, прямі офіційні посилання вступу й відомості про фото. Перевірено 8 жовтня 2026; це не повторний аудит бюджетів або загальних правил вступу.
- Такий самий каталог, як для Відня: спершу 3 картки, кнопка відкриває 9. Зміна країни й історія браузера повертають компактний список. Німецькі університети доступні через мобільне меню та `?country=de#universities`.
- Справжні 9 фото кампусів із Wikimedia Commons, 27 локальних WebP 480/800/1440, lazy loading. Оригінальні фото з повідомлення не були прикріплені. Авторство та ліцензії у футері й `THIRD_PARTY_NOTICES.md`; фото не генерували.
- Фіксований формат фото зберігає рівну висоту карток незалежно від пропорцій оригіналів. Австрійські 10 закладів, дані трьох країн і форма збережені.


## Нідерланди, хід216

- Третій напрям доступний у двох перемикачах, картках країн, мобільному меню та формі. Пряме посилання: `/indigo-vienna/?country=nl`; перезавантаження й історія браузера зберігають вибір.
- `app/netherlands.ts`: три маршрути вступу, чотири кроки, десять відповідей, бюджет на життя окремо від навчальної плати, каталог Studyfinder. Усі твердження мають офіційні джерела Nuffic, Study in NL, IND або конкретного закладу; дата перевірки NL — 08.10.2026. Для AT/DE залишено попередню дату19.09.2026.
- Пояснено HBO/WO, оцінку українського документа нижче VWO, винятки до загальних дедлайнів15січня/1травня, non-EEA тарифи та відсутність автоматичної пільги для нового українського вступника. Житло й стипендії не гарантовані.
- Фото каналу Амстердама: Supertrouper33, Wikimedia Commons, CC0. Локальні WebP480/800/900, без збільшення вихідної роздільності. Авторство у футері.
- Дані AT/DE і всі десять університетів збережені. Три кнопки мають коректний індикатор вибору після зміни країни, перенесення рядків, зміни розміру та reduced-motion.
- `docs/` є статичною збіркою нового кандидата. Окреме оновлення GitHub Pages у цьому ході не виконано.

## Запуск

Потрібен Node.js 22.13 або новіший.

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

Відкрити адресу Vite з шляхом `/indigo-vienna/`.

```sh
npm run build
npx tsc --noEmit
npm run lint
npm run preview
```

`dist/` створюється збіркою. `docs/` містить готову статичну версію для цього самого базового шляху. Для розміщення в корені домену змінити `basePath` у `site.config.ts` і перебудувати. GitHub Pages використовує `main:/docs`; `noindex,nofollow` збережено.

- Контрастний бюджет, чотири наочні кроки, зручні FAQ і світла форма консультації.
- Окрема мобільна композиція, меню з Escape та закриттям поза ним, природне збільшення тексту, адаптивні фотографії країн і локальний Manrope з кирилицею. Шрифт не звертається до Google під час перегляду.
- Спрощено стилі: старі невикористані композиції вилучено; `globals.css` визначає основу й елементи форми, `editorial.css` — поточну композицію та адаптивність.

## Оптимізація телефона, хід132

- Основний зміст довідника — 16 px; широка головна кнопка, компактні фото країн і університетів. Усі описи й посилання доступні без горизонтального свайпу.
- Кнопки консультації переходять прямо до `#consultation-form`, без автоматичного відкриття клавіатури. Старий якір `#consultation` також збережено.
- Під час читання нижня панель дає доступ до вступу, бюджету та консультації. Вона ховається біля консультації, при відкритому меню та фокусі поля; у низькому landscape не показується. Враховано нижню safe area, масштабування не заблоковано.
- Мобільне меню показує поточну країну й університети для Австрії та Німеччини. Поля залишаються не меншими за 16 px.
- У hero лише активне фото; `srcset/sizes` вибирає відповідний файл. Додано 32 WebP-похідні (міста480, кампуси480/800/1440), оригінали та історичне відео збережено. Кампуси на телефоні завантажуються під розмір thumbnail; усі зображення нижче першого екрана — lazy.
- Холодне завантаження Chromium390×844, DPR1/3, HTTP localhost без стиснення: старт 502799→403214 / 816275→590874 байтів; після переходу до університетів 1910911→457922 / 2224387→645582. Це порівняння обсягу даних, не оцінка часу на фізичній мобільній мережі.

## Зміст і заявка

Вміст AT/DE в `app/admissions.ts` і весь `app/universities.ts` збережено від commit `9ee0664`: усі відомості двох країн, 6 маршрутів вступу, 8 кроків, 20 FAQ, 10 університетів і джерела. Дата перевірки вступних правил AT/DE — 19 вересня 2026. Оновлення NL не є новим аудитом цін або правил AT/DE.

Форма перевіряє ім’я та етап, готує текст, дозволяє його скопіювати чи відредагувати. Посилання відкриває чат `@Natalia_Indigo` з чернеткою. Відвідувач сам надсилає повідомлення в Telegram. Автоматичного надсилання, зберігання даних на сервері чи в localStorage немає.

Контакти з попереднього сайту збережені. Вигаданих відгуків, гарантій, партнерств чи показників успішності немає. Добірка закладів не є рейтингом або переліком партнерів. Архітектурні зображення кампусів — наявні ілюстрації проєкту; їх не подано як доказ партнерства. Німецькі заклади додано у ході222 за точним списком власника.

Історичне відео збережено серед асетів, але воно не використовується й не завантажується сторінкою. Нових зображень або відео не генерували.
