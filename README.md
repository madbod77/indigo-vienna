# Indigo — вступ до Австрії та Німеччини

Сайт українською з двома окремими напрямами: умови вступу, бакалаврат і магістратура, мова та підготовка, бюджет, послідовність дій і відповіді на поширені запитання. Головна дія — заявка на безкоштовну консультацію Indigo.

Цей пакет містить локальне доопрацювання для комп’ютера й телефона. Публічний сайт цим оновленням ще не змінено.

- Сайт: https://madbod77.github.io/indigo-vienna/
- Австрія: https://madbod77.github.io/indigo-vienna/?country=at#guide
- Німеччина: https://madbod77.github.io/indigo-vienna/?country=de#guide
- Код: https://github.com/madbod77/indigo-vienna

## Запуск і публікація

Node.js 22.13+ (рекомендовано Node 24):

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Відкрийте адресу сервера зі шляхом `/indigo-vienna/`. `site.config.ts` задає базовий шлях. GitHub Pages публікує попередньо зібраний каталог `docs` із гілки `main`: після перевірки збірки оновіть `docs` точним вмістом `dist` і закомітьте.

Перевірки коду:

```sh
npx tsc --noEmit
npm run lint
```

## Інтерфейс — оновлення 24.09.2026, хід128

Помітно змінено композицію існуючого сайту: панорамний перший екран у глибокому індиго з великим заголовком Georgia, світла головна кнопка й перемикач Австрія / Німеччина. Використано ті самі локальні фото та адаптивні WebP; нових зображень або відео не генерували.

- Обидві країни представлені окремими видимими картками. Вибір відкриває відповідний довідник і синхронізує URL; повторний вибір не додає зайвого запису історії.
- Повноширинна шапка має прямий доступ до бюджету. На комп’ютері зміст довідника закріплюється під шапкою; на телефоні він залишається у потоці сторінки. Відступ переходу до секції вимірюється за реальною висотою навігації, зокрема зі збільшеним текстом.
- Три університети видно одразу; кнопка розкриває всі десять. Повні назви, описи, категорії та офіційні посилання збережені.
- Бюджет подано на світлому лавандовому тлі, фінальну консультацію — в індиго. FAQ показує загальну кількість питань для вибраної країни та кількість додаткових відповідей.
- Мобільна версія має власну композицію першого екрана, один список кроків з номерами збоку, читабельні повні тексти та меню, що закривається після переходу, Escape або натискання поза ним.
- Підтримано клавіатуру, видимий фокус, `prefers-reduced-motion`, зниження прозорості й збільшення тексту. Рух обмежено перемиканням станів; фото самостійно не рухаються.

Перевірка ходу128: `npm run build`, `npx tsc --noEmit`, `npm run lint`; 28 браузерних комбінацій країни, ширини 320–1920px і тексту200%; 20 FAQ з точними відповідями й URL, 6 описів вступу, 8 кроків, бюджети та 10 університетів; навігація, історія, валідація й редагування чернетки. Результат локальний; публічний сайт не оновлено.

## Зміст і заявка

- `app/admissions.ts`: окремі відомості й офіційні джерела для кожної країни. Перевірено 19.09.2026; плата, пільги та вступні правила потребують перевірки перед наступним набором.
- Оновлення дизайну від 24.09.2026 зберігає `app/admissions.ts` байт у байт від `576d724`: 158 полів двох країн, 6 описів вступу, 8 кроків, 20 FAQ та всі джерела. Дату перевірки умов не змінено: це оновлення вигляду та повноти вмісту, не новий аудит вступних правил.
- `app/universities.ts`: повернуто 10 закладів Відня зі старої версії `c7fd28f` — назви, категорії, описи й офіційні посилання. Перші три заклади видно одразу; повна добірка розгортається в розділі Австрії; він не є рейтингом або переліком партнерів. Повернуто також локальні назви й описи країн із наявних даних.
- `app/editorial.css`: стилі оновленої композиції. На телефоні фотографія завершує перший екран, а текст і перемикач мають природну висоту.
- `app/page.tsx`: вибір країни з прямими посиланнями, FAQ та форма.
- Форма перевіряє обов’язкові поля й показує текст заявки. Посилання відкриває чат `@Natalia_Indigo` з підготовленим текстом. Користувач сам натискає «Надіслати» в Telegram; сайт не показує вигаданого підтвердження відправлення. Є копіювання тексту та повернення до редагування.
- Дані форми не зберігаються на сервері або в localStorage. Telegram отримує текст лише після відкриття відповідного посилання. Немає прихованих відправлень, API-ключів чи платного сервісу.
- Відгуки, особисті дані консультантів і твердження про партнерства не вигадуються. Ці матеріали можна додати після підтвердження.
- Попереднє відео більше не використовується на сторінці й не завантажується під час перегляду. Історичні медіафайли залишені в репозиторії.
